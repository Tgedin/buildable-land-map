# Discovery log

One file per conversation: `YYYY-MM-DD-role.md` (e.g. `2026-11-03-cooperative.md`). No names or personal data, only role, context and learnings.

## Template

```markdown
# <role>, <date>

- **Who (role only):** housing cooperative member / small developer / architect / journalist
- **How they look for land today:**
- **What they'd check first on this map:**
- **What would make it useless to them:**
- **Would they share it? With whom?**
- **One change to make because of this conversation:**
```

## Questions that work

1. How did you find the last plot or building you looked at?
2. What information did you lack, and how long did it take to get it?
3. *(show the map)* What do you click first? What do you expect to see?
4. What would you need to trust this number?
